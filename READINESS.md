## Operational boundary

Genesis seals provider/model/settings, runtime provenance, world identities,
grants, retry budgets, attention bounds, operation limit, and continuity floor.
One resident lease owns advancement. Restart abandons an unterminated inference
explicitly and reuses retained contact bindings and idempotency keys. External
observations wake the subject immediately; quiet time eventually supplies an
instruction-free continuity pulse.

The stable core cannot call arbitrary code directly. It can invoke installed
world adapters, including the deliberately unrestricted shell, after an exact
realization has been bound and grants checked. There is no process isolation or
supervisor/worker split. File read and patch adapters enforce byte limits before
whole-file allocation.

The immediate projection is bounded near 200k tokens while exact evidence
remains content-addressed and retrievable. Active stake, open opportunities,
current consequence, contradiction material, and recent causal changes outrank
resolved history during compaction. Snapshots include exact objects and the
workspace rather than merely hashing an external mutable directory.

The macOS LaunchAgent uses one immutable release and a restart-safe resident
command. It contains no API key, and the CLI discovers ChatGPT's bundled Codex
binary even when the service PATH is sparse. Companion discovers the live resident CLI and
loads its matching V4 inspection module, so a newly packaged UI does not become
the authority over an older or newer body.

## Preserved limitations

- V3 state is not migrated into V4.
- A living V4 run cannot yet be rebound to a different provider, model, or
  implementation; no silent upgrade path is claimed.
- External services beyond the bundled worlds need their own exact adapter,
  effect semantics, idempotency boundary, and receipt contract.
- Unrestricted local authority is intentional and unisolated.
- Long-horizon trajectory quality remains a matter for lived observation, not
  an acceptance metric hidden inside this engineering release.
